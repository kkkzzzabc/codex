# 대화 내용 가운데 정렬

상태는 결정 필요입니다. 넓은 화면에서 제한된 본문을 가운데 배치할 수 있도록 합니다. 기본값은 기존 왼쪽 정렬을 유지합니다. [좌우 여백](02-horizontal-margins.md)과 공통 좌표 기준을 확정한 뒤 진행합니다.

## 검토할 배치 방식

| 방식 | 동작 | 영향 |
| --- | --- | --- |
| 본문 영역만 가운데 배치 | 본문은 가운데, 표·코드는 넓게 표시 | 블록별 시작 위치가 달라집니다. |
| 대화 영역 전체를 가운데 배치 | 사용자 메시지·답변·표·코드를 같은 경계에 배치 | 대화 영역 최대 폭이 별도로 필요하며 표·코드도 그 폭 안에 들어갑니다. |

줄마다 개별적으로 가운데 정렬하는 방식은 제외합니다. 문단과 목록의 시작 위치를 일정하게 유지하는 블록 배치를 사용합니다.

## 할 것

- [ ] 사용자가 원하는 배치 방식을 확정합니다.
- [ ] 좌우 여백을 제외한 영역 안에서 시작 위치를 계산합니다.
- [ ] 블록 종류에 따른 폭·시작 위치와 창 크기 변경 정책을 정의합니다.
- [ ] 선택·검색·링크·복사와 캐시가 변경된 위치를 공유하도록 합니다.

## 하지 않을 것

글자 간격을 늘리는 양쪽 정렬·줄별 중앙 정렬·원문 공백 추가는 하지 않습니다. 코드 블록의 내부 들여쓰기나 표 셀의 정렬은 변경하지 않습니다.

## 결정할 사항

- [ ] 본문만 배치할지 대화 영역 전체를 배치할지 결정합니다.
- [ ] 사용자 메시지·입력창·도구 출력과 경계를 맞출지 결정합니다.
- [ ] 제한되지 않은 넓은 표·코드와 본문이 섞일 때의 위치를 정합니다.
- [ ] 좌우 비대칭 여백과 가운데 정렬이 함께 설정된 경우의 기준 영역을 정합니다.

## 구현 영향

좌우 여백에서 만든 공통 배치 계산을 활용합니다. 블록별 너비 정책을 원문 위치 정보와 분리하고, 실제 화면 영역의 시작 좌표를 선택·클릭 처리에 전달해야 합니다. 구체적인 파일과 지원 모드는 설계 후 확정합니다.

## 완료 기준

- [ ] 기본 왼쪽 정렬의 출력이 유지됩니다.
- [ ] 홀수·짝수 폭에서 좌우 남는 공간 차이가 최대 1열입니다.
- [ ] 본문·목록·인용의 시작 위치가 블록 안에서 일관됩니다.
- [ ] 긴 표·코드·좁은 창에서도 내용이 잘리지 않습니다.
- [ ] 선택·검색·링크·복사와 실제 표시 위치가 일치합니다.

## 제거 조건

업스트림에 동일한 배치 방식과 여백 조합이 추가되면 설정 이전과 좌표 호환성을 확인하고 통합 또는 제거합니다.
