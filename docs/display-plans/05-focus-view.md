# 질문과 최종 답변에 집중하는 보기

상태는 결정 필요입니다. 질문과 최종 답변을 중심으로 표시하고, 도구 실행과 중간 설명은 필요할 때 펼쳐 볼 수 있도록 합니다. [전체 목록](README.md)의 다섯 번째 기능이며, 폭·여백 기능과 독립적으로 우선순위를 조정할 수 있습니다.

## 제안 동작

기본값은 기존 보기입니다. 집중 보기에서는 사용자 질문과 최종 답변을 유지하고, 도구 실행·결과와 중간 설명은 간단한 작업 상태로 접습니다. 작업 중임을 알 수 있는 표시와 중단 조작은 유지합니다. 상세 보기로 전환하면 보존한 내용을 확인할 수 있습니다.

Claude 설정의 `viewMode: "focus"`와 설치 코드에는 질문·요약·최종 답변 중심 표시라는 설명이 있습니다. 실제 집중 보기의 오류·승인·복사 동작은 검증하지 않았으므로 Codex의 요구사항으로 별도 정의합니다.

## 할 것

- [ ] 사용자 질문·최종 답변·진행 설명·추론 요약·도구 실행·도구 결과·오류·승인·질문을 분류합니다.
- [ ] 표시를 접어도 세션 기록과 상세 내용은 보존합니다.
- [ ] 오류·승인 요청·사용자에게 답을 요구하는 질문은 항상 표시합니다.
- [ ] 작업 진행·중단·완료 여부를 확인할 수 있게 합니다.
- [ ] 상세 보기와 집중 보기 사이 전환 경로를 제공합니다.
- [ ] 전환 전후 선택·검색·복사·스크롤과 재개 정책을 정의합니다.

## 하지 않을 것

숨긴 내용을 삭제하거나 모델에 전달되는 대화 기록을 축소하지 않습니다. 오류·승인 요청·사용자 질문을 자동으로 숨기지 않습니다. 도구 사용 권한이나 승인 정책을 바꾸지 않습니다. 모델의 시스템 프롬프트·중간 설명 생성 방식·자동 요약 모델 요청은 첫 구현에 포함하지 않습니다.

## 결정할 사항

- [ ] 실행 중 전환을 명령·단축키·기존 상세 보기 중 어떤 방식으로 제공할지 결정합니다.
- [ ] 완료된 도구 작업은 건수만 표시할지 한 줄 결과를 표시할지 결정합니다.
- [ ] 진행 설명과 추론 요약, 계획 블록을 어디까지 접을지 결정합니다.
- [ ] 실패 후 성공한 재시도와 여러 작업 중 일부 실패를 어떻게 표시할지 결정합니다.
- [ ] 검색과 전체 복사에 숨긴 내용을 포함할지, 표시 내용만 대상으로 할지 결정합니다.
- [ ] 설정을 시작 시 기본값으로만 저장할지 세션별 선택도 저장할지 결정합니다.

## 구현 영향

기존 대화 셀 분류·도구 출력 접기·전체 화면 상세 표시·이벤트 처리 경로를 먼저 조사합니다. 원문 데이터를 유지하고 표현 단계에서 표시 대상을 선택하는 방식을 우선 검토합니다. 화면 필터가 승인·질문 팝업까지 영향을 주지 않도록 경계를 분리합니다.

## 완료 기준

- [ ] 기본 보기에서 기존 내용과 조작이 유지됩니다.
- [ ] 집중 보기에서 질문·최종 답변·필수 사용자 조작이 보입니다.
- [ ] 도구 실행 중 정지한 것처럼 보이지 않으며 취소 조작이 가능합니다.
- [ ] 접힌 도구 결과·중간 설명을 상세 보기에서 다시 확인할 수 있습니다.
- [ ] 오류·승인·추가 질문·작업 실패를 누락하지 않습니다.
- [ ] 보기 전환·창 크기 변경·대화 재개 후에도 기록 손실과 중복이 없습니다.
- [ ] 검색·복사 범위가 정의한 정책과 일치하고 사용자가 범위를 알 수 있습니다.
- [ ] 폭·여백·정렬·간격 기능과 조합해 검증합니다.

## 제거 조건

업스트림에 집중 보기가 추가되면 필수 조작 노출·상세 내용 보존·검색과 복사 범위·기본값과 세션 저장 정책을 비교한 뒤 통합 또는 제거합니다.
