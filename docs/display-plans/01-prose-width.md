# 답변 본문 최대 폭

상태는 구현·검증 완료입니다. 2026-10-06의 Claude 검증을 참고하여 일반 답변과 추론 요약의 본문 최대 폭을 조절하는 기능을 구현했습니다. 별도 계획 블록과 표시 모드 전환은 이번 기능에 포함하지 않습니다. 개인용 패키지의 빌드 버전 수정은 다음 작업으로 남겼습니다. [전체 목록](README.md)에서 후속 작업의 순서를 관리합니다.

## 구현 동작

```toml
[tui]
max_prose_width = 80
```

40 이상의 정수를 받습니다. 값은 글자 수가 아닌 터미널 표시 열 수이며, 한글 등 넓은 문자는 기존 표시 폭 계산을 따릅니다. 실제 본문 폭은 설정값과 가용 폭 중 작은 값입니다. 왼쪽 출력 접두부는 별도이며 목록·인용의 들여쓰기는 본문 폭에 포함합니다. 설정을 생략하면 별도 제한 없이 가용 폭을 사용합니다.

설정은 시작·세션 활성화 시 읽으며 실행 중 변경 명령은 추가하지 않습니다. 40 미만·음수·소수·문자열은 기존 설정 역직렬화 오류로 안내합니다. 사용자 설정을 자동으로 작성하거나 변경하지 않습니다.

## 적용 대상

| 대상 | 이번 기능의 범위 |
| --- | --- |
| 일반 답변의 문단·제목·목록·중첩 목록·인용문 | 본문 폭 제한을 적용합니다. |
| 추론 요약의 같은 본문 요소 | 폭 제한을 적용하되 기존 표시 여부와 스타일은 유지합니다. |
| 일반 답변에 포함된 계획 설명 | 내용이 계획이라는 이유로 별도 처리하지 않으며 일반 답변과 같은 제한을 적용합니다. |
| 별도 계획 표시 | `ProposedPlanCell`, 계획 스트리밍, 계획 진행 목록에는 적용하지 않습니다. |
| 표·코드 블록·수식·다이어그램 등 별도 렌더링 블록 | 기존 가용 폭과 렌더링을 유지합니다. |
| 사용자 메시지·입력창·도구 출력·diff·메뉴·안내 화면 | 적용하지 않습니다. |

추론 요약 적용은 Claude 설치 코드에서 확인한 정책을 참고했습니다. Claude의 추론 화면은 참고 조사 당시 실행에 나타나지 않아 실제 폭은 측정하지 못했습니다. Codex의 추론 표시 종류는 Claude와 일대일로 대응한다고 가정하지 않습니다. Codex의 추론 요약은 렌더링·재배치 회귀 검사로 확인했습니다.

## Claude 검증 근거

Claude Code 2.1.290의 계획 승인 화면은 `maxProseWidth=80`이어도 본문이 최대 159열까지 표시됐습니다. 같은 계획의 `/plan` 미리보기는 100열 설정과 미설정에서 영문 비교 문단의 줄바꿈이 같았습니다. 계획 전용 화면은 본문 폭 제한의 적용 대상이 아니었습니다.

설치 코드에서는 추론 요약·상세 추론에 폭 제한을 전달하고, 간략 추론에는 전달하지 않았습니다. 추론 표시의 실제 실행 측정은 수행하지 못했으므로 이 결과는 코드 기준입니다. 일반 답변의 폭 제한은 앞선 실행 검증으로 확인했습니다.

계획 전용 화면과 추론 요약을 분리하는 근거로 사용하며, Claude의 UI 구조 전체를 복제하지 않습니다. 로컬 기록은 `/Users/kkkzzzabc/.cache/codex-plan-width-check-20261006/report.txt`와 `/Users/kkkzzzabc/.cache/codex-prose-width-check-20261006/report.txt`에 있습니다.
