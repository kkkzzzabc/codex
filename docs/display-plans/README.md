# Codex CLI 글 표시 개선 계획

답변의 읽기 편한 폭과 배치를 조절하고, 필요한 경우 질문과 최종 답변에 집중할 수 있도록 기능을 단계별로 추가합니다. 기능별 파일에서 범위와 완료 기준을 관리하며, 이 목록에는 순서와 상태를 기록합니다.

작성일은 2026-10-06이며, 1번 기능은 구현·검증을 완료했고 나머지는 계획 단계입니다. 계획 문서 작성은 기능 구현이나 빌드·테스트·CLI 실행의 승인을 뜻하지 않습니다. 1번의 설정과 동작은 구현 결과이며, 나머지 기능의 설정과 동작은 제안입니다. 결정 필요 항목은 구현 전에 확정합니다.

## 다음 작업에서 함께 처리할 항목

개인용 패키지의 빌드 버전 수정과 `gpt-6.1-sol` 요청 재검증을 다음 작업에 포함합니다. 현재 패키지는 `0.0.0`으로 빌드되어 서버의 모델 목록에서 해당 모델이 제외됩니다. 본문 폭 기능은 완료 상태로 유지하고, 버전 문제는 표시 기능과 구분하여 수정·검증합니다. 조사 결과와 후속 범위는 [운영 문서](../fork-maintenance.md#2026-10-06-개인용-패키지-모델-오류-조사)를 따릅니다.

## 공통 원칙

- 설정을 생략하면 기존 동작을 유지합니다.
- 표시 변경으로 응답 원문·도구 결과·세션 기록을 수정하거나 삭제하지 않습니다.
- 생성 중·완료 후·대화 재개·창 크기 변경에 동일한 정책을 적용합니다.
- 전체 화면과 일반 모드의 지원 범위를 명시하고 각각 검증합니다. 지원하지 못하는 경로를 숨기지 않습니다.
- 설정·렌더링·재배치·캐시·선택·링크 클릭·검색·복사를 함께 검토합니다.
- 기능 완료 시 [운영 지침](../fork-maintenance.md)의 커스텀 기록에 수정 영역·검증 결과·제거 조건을 추가합니다.

## 비교와 검증

변경 전에 동일한 원문으로 기존 출력을 확보합니다. 본문 폭은 제한 없음·80열·100열을 비교하고, 160→60→160열 화면 변경을 확인합니다. 한글·영문·숫자·긴 URL·인라인 코드·중첩 목록·인용·표·코드 블록을 포함합니다.

기존 `markdown_render_tests`, 스트리밍 검사, `app/resize_reflow_tests`, 전체 화면 선택·복사 검사를 변경 영역에 맞춰 활용합니다. 구체적인 검사 명령과 사용 가능한 도구는 구현 시 다시 확인합니다. 빌드·테스트·CLI 실행은 운영 지침의 승인 범위에서 수행하고, 각각의 성공 여부를 구분해 기록합니다.

## 확인한 근거와 한계

Claude Code 2.1.290의 전체 화면 모드를 PTY 가상 터미널에서 확인했습니다. 같은 영문 문단은 제한 없음에서 2줄, 80열에서 4줄, 100열에서 3줄로 표시됐습니다. 표·코드·사용자 입력은 본문 제한에서 제외됐고, 기존 답변은 창 크기 변경과 재개 시 다시 배치됐습니다.

설치된 설정 정의는 `maxProseWidth`를 40 이상의 정수로 정의하며, 표시 줄바꿈은 응답 원문을 변경하지 않는다고 설명합니다. [공식 릴리스 기록](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)과 [터미널 설정 문서](https://code.claude.com/docs/en/terminal-config#cap-response-width-in-wide-terminals)도 본문 제한과 표·코드 제외를 설명합니다.

실제 Ghostty 화면·클립보드·생성 중 프레임·일반 모드의 정상 조건 비교는 확인하지 못했습니다. 집중 보기는 설정과 설치 코드의 설명만 확인했으며 실동작은 검증하지 않았습니다. 좌우 여백·가운데 정렬·간격 조절은 Codex에 대한 제안이며, Claude와 동일한 동작을 확인한 기능이 아닙니다.

로컬 검증 자료는 `/Users/kkkzzzabc/.cache/codex-prose-width-check-20261006/report.txt`에 있습니다. 이 경로는 개인 환경의 참고 자료이며 계획 문서의 필수 의존 파일은 아닙니다.

추가 검증에서 계획 승인 화면은 80열 설정에도 터미널 폭까지 표시됐으며, `/plan` 미리보기의 줄바꿈은 100열 설정과 미설정에서 같았습니다. 추론 요약·상세 추론의 폭 제한과 간략 추론의 제한 제외는 설치 코드로 확인했으며 실제 추론 화면은 측정하지 못했습니다. 기록은 `/Users/kkkzzzabc/.cache/codex-plan-width-check-20261006/report.txt`에 있습니다.

1번의 수정 계획은 일반 답변과 추론 요약의 본문을 대상으로 하며, 별도 계획 블록은 제외합니다. 원문 표시 모드용 새 기능이나 모드별 폭 옵션은 만들지 않습니다. 좌우 여백 이후의 기능 순서와 범위는 유지합니다.

## 제외 범위

글꼴·글자 크기·터미널 셀 높이·터미널 창 자체 여백·테마 변경·실사용 설치·배포는 이 목록에서 제외합니다. 기존 Codex 테마와 터미널 설정을 우선 활용합니다. 자동 도구 설치나 전역 환경 변경도 포함하지 않습니다.

## 상태 갱신

각 기능 파일의 상태와 이 목록을 함께 갱신합니다. 결정 필요 항목을 확정한 뒤 구현 예정으로 바꾸며, 구현 후에는 검증 결과를 기록하고 완료 기준을 모두 충족한 경우에만 완료로 표시합니다. 업스트림에 동일 기능이 추가되면 설정과 세션 호환성을 확인한 뒤 커스텀 제거 또는 통합을 검토합니다.
